# Asilo Digital — Servicios

Landing estática de una página (Astro, TypeScript, CSS plano, pnpm). Ver [README.md](README.md).

- Copy visible en español. Reutilizar los tokens y clases de `src/styles/servicios.css`.
- Antes de subir cambios: `pnpm test`, `pnpm check` y `pnpm build`. Agregar tests para el comportamiento nuevo.
- Para cambios visuales, revisar en móvil y escritorio, con teclado y con `prefers-reduced-motion`.
